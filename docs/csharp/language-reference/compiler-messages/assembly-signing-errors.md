# Resolve errors and warnings for assembly signing

This article covers the following compiler errors and warnings:

<!-- The text in this list generates issues for Acrolinx, because they don't use contractions.
That's by design. The text closely matches the text of the compiler error / warning for SEO purposes.
 -->

- [**CS7027**](#anchor-tbd): *Error signing output with public key from file 'key-file' -- error message*
- [**CS7028**](#anchor-tbd): *Error signing output with public key from container 'key-container' -- error message*
- [**CS7032**](#anchor-tbd): *Key file 'key-file' is missing the private key needed for signing*
- [**CS7033**](#anchor-tbd): *Delay signing was specified and requires a public key, but no public key was specified*
- [**CS7088**](#anchor-tbd): *Invalid 'option' value: 'value'.*
- [**CS7090**](#anchor-tbd): *Attribute 'attribute' from module 'module' will be ignored in favor of the instance appearing in source*
- [**CS7091**](#anchor-tbd): *Attribute 'attribute' given in a source file conflicts with option 'option'.*
- [**CS7102**](#anchor-tbd): *Compilation options 'option' and 'other option' can't both be specified at the same time.*
- [**CS8002**](#anchor-tbd): *Referenced assembly 'assembly' does not have a strong name.*
- [**CS8003**](#anchor-tbd): *Invalid signature public key specified in AssemblySignatureKeyAttribute.*
- [**CS8102**](#anchor-tbd): *Public signing was specified and requires a public key, but no public key was specified.*
- [**CS8105**](#anchor-tbd): *Attribute 'attribute' is ignored when public signing is specified.*
- [**CS8106**](#anchor-tbd): *Option 'option' must be an absolute path.*
