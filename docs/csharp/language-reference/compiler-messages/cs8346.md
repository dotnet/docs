# Compiler Error CS8346

Conversion of a stackalloc expression of type 'TypeA' to type 'TypeB' is not possible.

The result of [`stackalloc`](../operators/stackalloc.md) is a block of memory allocated on the stack. The type of it can be a pointer of 'TypeA', if the local is either a pointer type or inferred (`var`). Or the type of stackalloc expression can be an instance of type `Span<T>`, where `T` is the unmanaged type.
In both cases, regardless of the type of local variable, result of stackalloc expression can't be explicitly cast to any type. Doing so breaks the compilers availability to correctly infer the allocation type.

## Example

The following samples generate CS8346:

```csharp
unsafe class Example
{
    public static void Main()
    {
        // CS8346: Conversion of a stackalloc expression of type 'int' to type 'int*' is not possible
        Span<int> stackSpan = (int*)stackalloc int[100];

        // CS8346: Conversion of a stackalloc expression of type 'int' to type 'int*' is not possible
        int* stackInt = (int*)stackalloc int[100];

        // CS8346: Conversion of a stackalloc expression of type 'int' to type 'int*' is not possible
        var stackVar = (int*)stackalloc int[100];
    }
}
```

## To correct this error

Avoid using explicit cast. Let the compiler infer the correct type.

```csharp
unsafe class Example
{
    public static void Main()
    {
        // No CS8346. Type of stackalloc expression is Span<T>, where T is int
        Span<int> stackSpan = stackalloc int[100];

        // No CS8346. Type of stackalloc expression is int*
        int* stackInt = stackalloc int[100];

        // No CS8346. Type of stackalloc expression is int*
        var stackVar = stackalloc int[100];
    }
}
```
