# Compiler Error CS0257

An __arglist parameter must be the last parameter in a parameter list

When implementing a method or function with `__arglist`, the `__arglist` parameter must be listed as the last of that method's or function's parameters.

## Example

The following sample generates CS0257:

```csharp  
using System;

public class Example
{
    public void MethodWithArglist(int a, __arglist, string s)  // CS0257
    {
    }

    public void Main()
    {
        MethodWithArglist(1, __arglist("arguments"), "2");
    }
}
```

## To correct this error

List the `__arglist` parameter as the last one:

```csharp
using System;

public class Example
{
    public void MethodWithArglist(int a, __arglist)
    {
    }

    public void Main()
    {
        MethodWithArglist(1, __arglist("arguments"));
    }
}
```
