# C# programming concepts

C# is a modern, object-oriented, and type-safe programming language that combines high-level developer productivity with low-level performance and control. This section surveys foundational programming concepts and paradigms supported by C#.

## Core programming paradigms

C# supports multiple programming paradigms that work together seamlessly:

| Topic | Description |
| --- | --- |
| [Object-oriented programming](../../fundamentals/object-oriented/index.md) | Learn how to model applications using classes, inheritance, polymorphism, and encapsulation. |
| [Functional programming techniques](../../fundamentals/tutorials/functional-techniques.md) | Use immutability, pattern matching, records, and expression-bodied members to write concise and predictable code. |
| [Generics](../../fundamentals/types/generics.md) | Design type-safe data structures and algorithms that defer the specification of types until instantiated by client code. |
| [Asynchronous programming](../../asynchronous-programming/index.md) | Write nonblocking, scalable code using the `async` and `await` keywords and the Task-based Asynchronous Pattern (TAP). |
| [Language Integrated Query (LINQ)](../../linq/index.md) | Query and transform data from diverse sources using strongly typed query expressions and standard query operators. |
| [Memory and performance](../../advanced-topics/performance/index.md) | Optimize performance using ref structs, stack allocation, spans, and memory safety features. |
