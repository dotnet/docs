# .NET Framework November 2026 cumulative update preview

_Released November 19, 2026_

## Summary of what's new in this release

- [Security improvements](#security-improvements)
- [Quality and reliability improvements](#quality-and-reliability-improvements)

### Security improvements

There are no new security improvements in this release. This update is cumulative and contains all previously released security improvements.

### Quality and reliability improvements

#### .NET Runtime

- Addresses an issue with Canadian time zone settings where the wrong daylight saving time rule caused the inaccurate UTC offset for the first hour of January 1, 2027. (*Applies to: .NET Framework 4.8.1*)

## Known issues in this release

This release contains no known issues.
