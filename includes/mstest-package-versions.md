> [!NOTE]
> The package versions shown are examples. The versions generated by `dotnet new mstest` depend on your .NET SDK. Templates and downloaded samples might not use the latest NuGet package versions.
>
> To check for updates after you create and run your tests, run [`dotnet package list --outdated`](../docs/core/tools/dotnet-package-list.md) from the test project directory. Use [`dotnet package add <PACKAGE_NAME>`](../docs/core/tools/dotnet-package-add.md) to update a package reference to the latest compatible stable version. Review release notes for breaking changes before you update, and run `dotnet test` again afterward.
>
> If you use .NET 9 SDK or earlier, use `dotnet list package --outdated` and `dotnet add package <PACKAGE_NAME>` instead.
